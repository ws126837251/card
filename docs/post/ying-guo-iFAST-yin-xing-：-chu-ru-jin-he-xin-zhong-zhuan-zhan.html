0 开户费、0 年费、0 管理费。开出来是英国持牌数字银行账户，不是电子钱包。英镑走英国本地账户，欧元、美元、港币、人民币走国际账户。后面给 Wise 入金、接券商、试绑英区 PayPal，都会用到这组账号。钱要回到国内，App 里可以把外币汇到支付宝。

iFAST简单介绍

简单地说，iFAST Global Bank 是英国数字银行，母公司是新加坡上市的 iFAST 集团。银行业务拿过英国 PRA 授权，并受 PRA 和 FCA 监管。符合条件的存款参加 FSCS，页面上看到的上限是每人 120,000 英镑，以官网为准。

国内银行 App：人民币转账扫码很顺，英镑、欧元、对接海外券商经常卡住。

Wise：换汇、多币种收款强，对加密相关来源很敏感，也不是英国持牌银行账户。

iFAST 卡在银行这一层：身份证加大陆地址可以远程开，账户里能放多种货币，英镑有 Sort Code，国际侧有 IBAN / SWIFT,支持 SEPA 可以接收海妖交易所的欧元/英镑

英国本地账户：收英镑。对方在英国境内转，走 FPS 一类本地通道，常见秒到、这一段不另收费。

国际账户：收欧元、美元、港币、人民币等。走 IBAN / SWIFT，支持 SEPA

它不是 N26 的完整平替，也不是 Wise 的替代品。
更稳的用法是两个都开：
iFAST 负责银行账户和收付，
Wise 负责换汇和周转。
没有港卡的人，会把它当成海外资金的中转节点。

三、开户之后怎么入金

收到开户成功邮件，用注册邮箱登录。首次要设密码，再注册保安编码器，也就是人脸或指纹一类二次验证。邮箱再收一次码，扫一次脸，才能进首页。

账户信息在 左上角三条杠 → 银行明细。

  • 在英国境内：Sort Code、账号、户名。只收英镑。

  • 国际的：IBAN、SWIFT、户名。支持 SEPA 用来收其他币种或跨境汇款。

入金操作

第一笔钱只从本人名下、能解释来源的账户转入。不要让朋友代付，不要从第三方换汇商直接打，不要用自己也说不清的钱包测试。

  1. 兴业银行

在兴业银行用人民币购买 GBP 现汇，购汇用途选择因私旅游

如果之后取消汇款，GBP 可以再结汇成人民币，但银行买卖价之间存在价差，来回兑换通常会有损失

外汇汇款时，账户中除了要有足够的 GBP，还要预留人民币支付银行费用，提交汇款后，兴业银行先冻结了 200 元费用。

注意这里的费用承担方式应选择 OUR汇款人承担，iFast 付款信息中有明确指出。不同银行和收款路径的选项可能不同，操作时应以 iFast 页面和汇出行提示为准。

购汇和汇款用途可根据真实情况填写，如果遇到审核，直接向银行确认所需资料，并确保汇款用途和证明材料真实一致。

特别注意不要混淆两个地址：

  • Beneficiary Address：本人作为收款人的地址，可选择英国酒店地址

  • Bank Address：Wise 页面提供的收款机构或银行地址

提交前建议对照 iFast 页面逐字复核姓名、IBAN、SWIFT/BIC 和 Reference。首次入金应从本人同名账户汇出，否则可能被拒收或要求额外验证。

银行审核通过并汇出后，等待 iFast 收到 GBP。到账时间会受到汇出行、中转行、周末及合规审核等因素影响。

  1. wise入金

激活最省事的一条：Wise 英镑账户 → 汇款 → 添加英镑收款人 → 填 iFAST 的 Sort Code、户名、账号 → 先转 1 英镑。走英国本地，常见很快到账。到账后，这个户才算真正能用。最低激活金额我这边是 1 英镑等值，以你账户提示为准。

四、注意事项

  1. iFAST 可以接收部分加密相关银行的汇款，不能出金到 U 卡、交易所。用 iFAST 给 Kraken 打钱，被提示收款方可能与加密货币相关，直接拒了。这条当中转，不要当双向通道。

  2. SEPA 欧元是后加的能力。英镑 FPS 还在；用国际侧转账用个人 IBAN 走 SEPA 收欧元。

  3. 资金回国 1.5%返现 损耗低 每月扫码支付消费最高享受2000英镑 返现额度

  1. 给 Wise 入金、试绑英区 PayPal、对接 IBKR / 嘉信一类券商，是这个户更常见的用法。

  2. 港卡往美股、港股券商直接打钱如果被卡住，英国账户才会显得更必要。

  3. 长期零余额、零交易，有关户风险。留一点余额，偶尔登录。
