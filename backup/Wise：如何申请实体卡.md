# 一、开户准备

1. 已经拥有 Wise 个人账户
2. Wise 个人账户已经完成身份认证
3. Wise 个人账户已经入金并正常使用过
4. 账户最好已经稳定使用一个月以上
5. 准备好真实、可解释的企业或自雇业务信息
6. 准备好后续可能需要的地址证明、收入证明或业务证明材料
如果你的 Wise 个人账户刚注册不久，没有入金记录，也没有稳定使用记录，不建议马上开通企业账户。

新账户直接开企业账户，触发风控的概率可能更高。

# 二、注册流程

1. 打开 Wise 主页，点左上角头像。

3. 企业位于哪个国家/地区，选择你工作所在的国家，推荐选英国。

4. 选企业形式（自雇人士），填企业信息。

# 四、风险说明

Wise企业账户一定存在风控风险，尤其是以下情况：

- 第一，个人Wise账户本身就存在异常。

例如账户刚注册、没有入金、间隙改区、姓名信息不一致、资料不完整等。如果此时再开通企业账户，更容易被要求提交额外材料。

- 第二，企业账户封闭充值、往来或资金来源复杂。

如果企业账户出现多笔不同来源资金、间隙转入转出、大额交易或用途不清晰，明智的可能会要求提供收入证明、地址证明、业务证明或资金来源说明。

- 第三，企业资料与实际使用情况不相符。
 
例如填写的是普通自雇业务，但账户实际进行投资、加密货币、金融内或高风险交易，这可能触发更严格的审核。

- 第四，不建议开通不需要的50英镑企业收款账户。

该功能可能涉及更完整的企业收款权限、税务信息和更高等级风控。如果你并狮子用途，不建议盲目开通。

- 第五，不建议使用加密货币相关资金直接与Wise企业账户交互。

明智的对加密货币相关资金流通常比较敏感，容易触发审核或限制。

- 第六，企业账户和个人账户虽然相对独立，但不要认为完全没有影响。

原教程认为企业账户风控不会直接影响个人账户，例如企业账户充值被审核时，个人账户仍可正常使用。但实际情况仍以明智风控判断为准。如果账户之间存在明显关联，仍可能被整体审查。
