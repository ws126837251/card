# 一、Wise 是什么

wise 对大陆用户最有价值的场景，不是刷卡消费，而是资金中转和换汇：
接收 Stripe、Payoneer、Upwork、Fiverr 等平台款项后中转；与港卡、海外券商配合出入金；向海外汇款（留学缴费、境外支付）；用虚拟卡支付境外订阅服务；通过 DBS 虚拟账户作为轻量港卡替代。

不适合的场景：长期存放大额资金（Wise 不生息，且会触发风控）；加密相关资金流转；需要银行资质的正式场合。

# 二、开户流程

- 用真实信息+地址
- 身份证和护照，两套证件可以独立开户

但身份证注册有三个护照没有的优势：
1. 无需入金激活；
2. 有资格申请香港 DBS 虚拟账户；
3. 无需提供地址证明。

已经用护照注册过 Wise 的账户如果运行良好就继续用，不要为了这几个优势注销重开——清零交易历史，风控会更严。

---

1.打开 [wise官网](https://wise.com/invite/ilpn/xjz7c7k) ，选择「个人账户」，居住地按国内身份信息如实填写。
整个注册过程用国内网络直接操作即可，不需要科学上网，反而频繁切换 IP 会触发风控。

2.填写个人资料。姓名必须用拼音全大写，First Name 填名（如 SAN），Last Name 填姓（如 ZHANG）——这一步极容易填错。

填中文会导致日后收款姓名不匹配被退回，改名需要联系客服加手持证件拍照，非常麻烦。

地址填国内真实地址，所有内容用拼音或英文，中文会报错。需要填电话时，写在地址第二行：Tel: 138xxxxxxxx。

<img width="643" height="641" alt="Image" src="https://github.com/user-attachments/assets/6b1a6059-1cb7-4be9-a0a4-36d93407d2a4" />

3.身份验证，选「身份证」，上传正反面。注意必须现场拍摄，不支持从相册选图；光线要充足，建议深色背景；模糊或遮挡直接被拒。部分情况下还需要一张手持身份证的自拍照。

4.等待审核，通常 1-2 个工作日。审核期间如果收到邮件询问是否担任政府要职或重要公职，直接回复「No」——不回复会导致汇款被原路退回。

5.第五步：审核通过后，在账户内添加需要的货币（美元USD、英镑GBP、欧元EUR、港币HKD、菲律宾PHP、新加坡SGD），这些必备的优先添加，每种货币生成对应本地账户信息即可。

# 三、入金激活

尽量入金外汇，人民币手续费略高
推荐入金用
- Apple Pay
- 英国monzo
- ifast银行
一定要本人实名的才能入金，不要异名入金，根据要求入金金额

# 四、避坑指南

1. 不要频繁改 IP：虽然国区号耐用，但也不要今天美国明天新加坡，保持稳定。
2. 关于实体卡：目前中国地址注册的 Wise 不发实体 Visa 卡。
